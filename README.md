# Базы данных — PostgreSQL

Учебные работы по дисциплине «Базы данных» (ОмГТУ).
СУБД: PostgreSQL 16, клиент: pgAdmin 4.

## Состав

### Учебный пример из пособия — база данных `sales`

Служба, оформляющая заказы на товары. Семь таблиц.

| Файл | Содержание |
|---|---|
| [lab2_sales_db.sql](lab2_sales_db.sql) | лабораторная работа № 2 — создание базы данных |
| [lab3_sales_tables.sql](lab3_sales_tables.sql) | лабораторная работа № 3 — создание и связывание таблиц |

### РГР, вариант 11 «Автостоянка» — база данных `parking`

Учёт договоров хранения, транспортных средств, событий въезда и выезда
по распознаванию государственного номера и частичных платежей.
Девять таблиц, 51 ограничение целостности.

Каталог [rgr](rgr/), подробное описание — в [rgr/README.md](rgr/README.md).

| Файл | Содержание |
|---|---|
| [rgr/lab2_parking_db.sql](rgr/lab2_parking_db.sql) | создание базы данных |
| [rgr/lab3_parking_tables.sql](rgr/lab3_parking_tables.sql) | 9 таблиц, ограничения UNIQUE / DEFAULT / CHECK, 15 внешних ключей |
| [rgr/lab4_parking_data.sql](rgr/lab4_parking_data.sql) | вставка, обновление и удаление данных |
| [rgr/demo.sql](rgr/demo.sql) | демонстрация выполненной работы по пунктам задания |
| [rgr/test/](rgr/test/) | проверка ограничений целостности, контроль структуры БД |
| [rgr/ОТЧЁТ_РГР_Автостоянка.md](rgr/ОТЧЁТ_РГР_Автостоянка.md) | отчёт по работе |

## Запуск

```powershell
cd rgr
.\run_all.ps1 -Password "<пароль_postgres>"
```

Скрипт находит `psql.exe`, выполняет файлы по порядку и сохраняет
протоколы выполнения в каталог `rgr\log`.
