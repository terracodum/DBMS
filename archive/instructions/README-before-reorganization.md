# Базы данных — PostgreSQL

Учебные работы по дисциплине «Базы данных» (ОмГТУ).
СУБД: PostgreSQL 16, клиент: pgAdmin 4.

## Работа в Jupyter

Основной формат лабораторных — `.ipynb`: пояснения, запросы и результаты
собраны в одном месте. Отдельно редактировать SQL-файлы не требуется.

1. Установить зависимости: `python3 -m pip install -r requirements.txt`.
2. Открыть ноутбук в VS Code с расширениями Python/Jupyter или JupyterLab.
3. Выбрать Python с установленными зависимостями и выполнять **Run All**.

PostgreSQL должен быть запущен. Подключение настраивается через `PGHOST`,
`PGPORT`, `PGUSER`, `PGPASSWORD` или `.pgpass`; по умолчанию localhost:5432
и текущий пользователь ОС. Пароль в ячейках не сохраняйте.
`PGDATABASE` переопределяет базу конкретного ноутбука; обычно его можно не задавать.

Учебная база `sales`: [создание БД](../../labs/lab02/lab2_sales_db.ipynb), затем
[создание таблиц](../../labs/lab03/lab3_sales_tables.ipynb). Данных для `sales` в исходном проекте нет.

Если `parking` уже заполнена, можно сразу переходить к ЛР5.
ЛР3 и ЛР4 создают таблицы, поэтому рассчитаны на первый запуск;
существующие таблицы автоматически не удаляются. При ошибке транзакция
откатывается; после прерывания выполните `conn.rollback()` перед повтором.
ЛР3 и ЛР4 сохраняют изменения в последней ячейке, поэтому не пропускайте её.
ЛР5 с учебными примерами отменяет временные изменения в конце.

## Запуск

```powershell
cd rgr
.\run_all.ps1 -Password "<пароль_postgres>"
```

Скрипт находит `psql.exe`, выполняет файлы по порядку и сохраняет
протоколы выполнения в каталог `rgr\log`.
