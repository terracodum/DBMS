# Проверка дубликатов

## 1. Точные копии

Все исходные рабочие файлы, включая игнорируемое учебное пособие, проверены
по SHA-256. Каталоги .git и .claude и служебные .DS_Store исключены.
**Полностью одинаковых файлов не найдено. Ничего не удалено как дубликат.**
Перед изменениями сохранена резервная копия исходных файлов вне репозитория.
При переносе дополнительно проверены контрольные суммы всех перемещённых файлов.

## 2. Похожие версии

| Файлы | Результат |
|---|---|
| Два Markdown-отчёта [ЛР4](../labs/lab04/) с суффиксом FIT и без | Около 80% совпадения строк; тексты и структура различаются. Сохранены оба |
| Основной [отчёт РГР](../reports/rgr/ОТЧЁТ_РГР_Автостоянка.md) и [расширенный](../archive/full_version/ОТЧЁТ_РГР_Автостоянка.md) | Около 81% совпадения строк; расширенный вариант оставлен в архиве |
| Markdown и DOCX одного отчёта | Разные форматы представления, а не точные копии |
| DOCX с FIT и без | Байтовое содержимое различается; семантическая и визуальная эквивалентность не проверялась. Все версии сохранены |
| SQL в архиве и код в ноутбуках | Повторение запросов намеренное: архив исходников и рабочие ноутбуки |

Проценты — сходство последовательностей строк Markdown по SequenceMatcher,
а не оценка смысловой или визуальной эквивалентности.

## 3. Найденная несогласованность

В прежних README и обоих скриптах запуска упоминался файл
`lab5_textbook_example.sql`, которого в репозитории не было.
Его вызов исключён из архивных скриптов; учебные примеры сохранены в
[lab5_textbook_example.ipynb](../labs/lab05/lab5_textbook_example.ipynb).
Прежние README хранятся как исторические инструкции и не задают текущий запуск.
