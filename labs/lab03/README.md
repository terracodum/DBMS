## 2. Как читать эту работу

Сначала создаются таблицы и ограничения, затем вставляются 91 строка и выполняются обновления. После добавления тарифа получается 92 строки. Демонстрационные удаления откатываются. Проверки целостности из отчёта доступны в [архивном SQL](../../archive/sql/parking/test/integrity_tests.sql) и [протоколе](../../archive/logs/integrity_tests.log); ноутбук их пока не запускает.

[Пример на sales](lab3_sales_tables.ipynb) сохранён для справки; обязательный путь — parking.
